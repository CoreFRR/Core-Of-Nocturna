# CoreFRR — site des projets

Site statique (GitHub Pages). Pour ajouter un projet, ajoute un bloc dans `projects.js`.

## Mise en ligne
1. Crée un dépôt nommé `CoreFRR.github.io` (le site sera sur https://corefrr.github.io), ou n'importe quel nom pour une adresse `/nom`.
2. Pousse ces fichiers à la racine de la branche `main`.
3. Settings → Pages → Source : *Deploy from a branch* → `main` / `(root)`.
